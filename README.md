# ShopBoard | شوب بورد 🎮✨

متجر إلكتروني احترافي لمعدات المكتب (Desk Setup) والأجهزة التقنية، مزوّد بـ **مُنشئ مساحة العمل ثلاثي الأبعاد (3D Desk Builder)** التفاعلي بالكامل عبر Three.js و WebGL.

---

## 🌟 أبرز المميزات

1. **مُنشئ مساحة العمل 3D (3D Desk Builder):**
   * بيئة تفاعلية 3D حقيقية بمحرك Three.js وإضاءة استوديو سينمائية متطورة.
   * إمكانية تدوير الكاميرا 360 درجة، تقريب المشهد وفحص أدق التفاصيل.
   * **سحب وإفلات مباشر (Direct Pointer Drag & Drop):** اسحب المنتج من القائمة العائمة وأفلته في أي نقطة على سطح المكتب.
   * **إعادة التحريك والتدوير 360°:** انقر على أي قطعة على السطح لتغيير مكانها أو تدويرها.
   * **التكامل الذكي مع السلة:** يدعم تعدد النسخ (مثل شاشتين أو سماعتين) ويضاعف الكمية والسعر الإجمالي في سلة المشتريات بنقرة واحدة.

2. **سيت أب الألعاب المتكامل (Gaming Battlestation):**
   * صندوق حاسب ألعاب احترافي (Aorus Gaming PC) بواجهة زجاجية ومراوح ARGB ومكونات داخلية.
   * شاشة ألعاب منحنية فائقة العرض 34 بوصة (Gigabyte Curved Gaming Monitor).
   * لوحة مفاتيح ميكانيكية مضيئة، ماوس مريح، لباد مكتب صوفي، وسماعات استوديو.

3. **الأداء والسرعة:**
   * مبني بـ Vanilla JS و Vite وخفيف للغاية.
   * تحميل كسول كود الـ 3D (Code-Split / Lazy Loading) عند فتح الاستوديو فقط.

---

## 🚀 التشغيل المحلي (Getting Started)

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء الإنتاج
npm run build
```
